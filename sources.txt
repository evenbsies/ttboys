# TVBox 每日源抓取 · 种子列表
# 每行一个 URL，# 开头为注释。支持两类：
#   1) 索引类：返回源地址列表（JSON 数组或每行一个 URL 的文本），脚本会自动展开
#   2) 配置类：直接是 TVBox 配置 JSON（含 sites 字段）
#
# 注意：
#   - raw.githubusercontent.com 在国外服务器（GitHub Actions）可直接访问；
#     国内运行时脚本会按需自动走内置镜像（ghfast.top / gh-proxy.com / gh.ddlc.top）。
#   - 失效的源会自动跳过并在 status.json 中记录，不影响整体。
